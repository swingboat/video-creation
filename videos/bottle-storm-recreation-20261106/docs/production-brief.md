# 瓶中风暴：参考重建

参考：https://x.com/guanmo_ai/status/2118258208045494688

目标：14 秒、24fps、1280×720。保留横置玻璃瓶、双桅帆船、灯塔、鱼草、粉色儿童卧室、暖灯与冷色雷光的构图关系。无字幕、无旁白、无配乐。

技术：Blender Cycles 本地路径追踪；Python 程序化创建全部模型、材质和场景；解析波面 + 船底四点采样；船体位置和姿态烘焙关键帧；8 轮闪电曲线 + 同步辅助光；NumPy/SciPy 生成风雨、海浪与延迟 90ms 的雷声；Remotion 组合画面与声音。

这是依照公开成片重新制作的研究版本，并非原始作者工程。没有原始几何、材质节点、镜头与随机种子，不能逐像素相同。参考帧仅用于制作对照，不用作任何渲染背景或视频帧。

分段：0–2 秒海面轻摇；2–12 秒波浪增强并发生八轮闪电；12–14 秒逐渐回落。摄影机仅轻微推近，保持微缩场景可读。

路径隔离：项目文件、Python venv、npm 包与缓存、Blender 配置、受控临时目录、检查图与成片均位于本目录。系统安装的 Blender/FFmpeg/Chrome 为外部工具，不属于其他视频项目依赖。macOS Metal 驱动可能写入其不可配置的系统级编译缓存；不能将这一缓存宣称为项目内隔离。参考读取使用已有 Tabbit 浏览器会话，浏览器自身日志和缓存由浏览器管理。

最终制作配置：Blender 5.2.2 / Cycles / Metal GPU / 1280×720 / 24fps / 336 帧 / 每帧 16 samples + 降噪。玻璃与水保留实际折射；清水采用表面透射，不额外添加几乎无密度的体积介质。全部帧逐帧路径追踪，未使用补帧或跨帧复制。
