# 樱木花道与晴子：放学后的练习

30秒，1280×720，24fps，720帧，横版。原漫画前期人设：红色飞机头、浓眉、强壮高大的樱木；长发齐刘海、温柔但关心篮球的赤木晴子。樱木穿红色湘北10号球衣；晴子穿白色短袖衬衫、红色领结、深蓝百褶裙。全部镜头保留同一衣着、场景和日照方向。

地点：湘北高中旧式体育馆，木地板、绿色下墙、上方窗户、固定篮板，无现代大型比赛场馆。故事为原创同人练习小片段，并非复刻某一原作分镜。视觉尽量忠于原角色，不能宣称逐帧等同官方原画。

## 叙事与初步镜头
0–4秒，同框，晴子鼓励持球的樱木。
4–8秒，晴子中近景，微笑、点头示意。
8–12秒，樱木近景，害羞挠头后认真看向球场。
12–16秒，樱木空手练习基本站姿，晴子在旁观察。
16–19秒，樱木双手收球、屈膝准备。
19–22秒，晴子轻轻拍手。
22–26秒，樱木轻握拳、神情恢复自信。
26–30秒，同框微笑与点头，回到两人的关系。
镜头根据实际画面验收可调整；所有人物片段使用原速连续源帧，不延长冻结，不倒放循环补时。

## 技术
内置imagegen统一同框原画，再生成匹配机位；LTX-2.3 q4 / MLX本地整幅图生视频；先做49或73帧关键动作；每次一个GPU任务；Gemma与连接器顺序加载，11GiB MLX额度，默认float32计算。Remotion 4.0.541 / React 19.3.1剪辑。环境声为主，不克隆原版演员声音。
