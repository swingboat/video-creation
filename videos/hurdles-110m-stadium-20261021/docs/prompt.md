# 110 米栏 · HURDLE / 110 — 实现提示词

创建一个可直接打开的独立 HTML 文件，呈现一名成年男子运动员在真实尺度的体育场进行 110 米栏训练。借鉴参考帖的 Three.js/WebGL 实时场景、精细材质、持续环境运动和自然运动规则，但优先保证人体和跨栏动作质量。

## 视觉与人物
- 写实运动员，真实的人体比例、面部、耳朵、眼睛、肌肉、手指和跑鞋；贴身田径背心、短裤、号码布。允许下载公开的高质量人物模型、扫描头部、贴图、骨骼与动作库，并记录来源。不得用简单球棍人作为最终人物。
- 上午柔和侧光，真实投影、接触阴影、细颗粒塑胶跑道、白色分道线、金属栏架、草坪、看台、顶棚、灯柱和体育场记分屏。环境有空间深度，材质不呈塑料玩具感。
- 运用连续、有解剖结构的网格或高质量下载模型；全片保持同一人物。手部握拳自然，头部注视前方，躯干随步态产生小幅扭转，呼吸与摆臂有节奏。

## 运动逻辑
- 正规男子 110 米栏：10 栏，首栏距起点 13.72 米，栏间距 9.14 米，末栏距终点 14.02 米，栏高 1.067 米；训练模式可降低栏高，但明确标识。
- 形成准备、起跑加速、栏前调整、低平过栏、落地、栏间三步、冲线和减速的完整训练循环。
- 跨栏时前腿提膝后向前伸展，后腿屈膝并向外侧打开，躯干前倾，手臂平衡；落地前腿向下回扒，后腿迅速前收，避免双腿对称跳跃。
- 脚掌在支撑阶段固定于地面，不持续滑动；飞行期与接触期区分清楚。横杆保持独立且不穿过身体。路径、步频与姿态一致。
- 以统一模拟时间驱动，支持暂停、0.25/0.5/1 倍速、拖动进度和精确定位，慢动作时不能改变轨迹。

## 镜头与界面
- 默认低机位侧前方跟拍，让脸、身体、栏架与接触阴影可见；提供侧面技术观察、追随、体育场全景等镜头。
- 全屏画面，轻量中文界面，体育转播式排版，奶白/深墨色文字加少量酸橙色强调。左上角片名，右上角训练状态，底部控制和进度；信息不遮挡运动员。
- 显示模拟时间、距离、当前栏序、动作阶段、速度；数值来自当前状态，说明是动作演示而非运动科学测量。
- 支持键盘、鼠标和移动端；隐藏界面可获得干净画面。提供环境声音开关，在用户交互后启用音频。
